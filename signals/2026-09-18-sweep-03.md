## Evidence sampled this sweep

- PPWR is now applicable (12 Aug 2026) and current products already advertise per-product compliance, supplier portals, missing-evidence collection and DoC generation (PPWR Toolkit, Polygon One, PAQR, LIVO). This validates pain but makes generic PPWR compliance a poor wedge.
- EU Pay Transparency tooling already offers payroll upload, job architecture, salary bands, employee-request handling, joint assessments and audit trails (PayComply, MultiComply). Generic compliance is crowded.
- Accounting document chasing is explicitly marketed as an 8–12 hour/month pain and multiple 2026 products automate requests/reminders (Paprstack, MonthlyDocs, Beesight, Fiscora). Pain is unusually clear; generic collection is commoditizing, so focus should move downstream to exceptions that block paid work.
- AI Act Article 50 / AI-literacy obligations are active; several SME compliance products already exist. Generic inventory/checklist is weak unless tied to continuously changing production surfaces.
- Spain has just created a one-month preferred evaluation route for strategic investments; high willingness-to-pay may exist but transaction frequency/distribution look weak for a software-first experiment.

## Ranked queue for falsification

1. **Accounting Close Exception Router** — not document collection. Detect which client/file exception blocks which close/tax/payroll task, rank by deadline/revenue/staff dependency, and generate the smallest next action. Distribution advantage: direct access to Spanish asesoría workflows; cheap falsification with anonymized process samples before building.
2. **Supplier Evidence Change Propagator** — certificate/declaration/spec changes propagate to affected packaging/products/claims/customers. Start with PPWR as forcing function but test whether the graph is valuable beyond PPWR.
3. **Professional Services Scope-Leak Ledger** — map incoming client request/work performed against engagement scope and identify unbilled/out-of-scope work before it disappears into goodwill. Buyer pain is economic rather than compliance-driven.
4. **CAE Work-Blocking Exception Router** — subcontractor evidence expiry/missing docs → exact site/work package/person blocked → next action. Spain-specific distribution needs validation.
5. **AI Production Disclosure Regression Monitor** — continuously find AI-interaction/content surfaces whose required disclosure disappeared or became inconsistent after releases. Must prove this is not merely accessibility/compliance scanning.

## Engine decision

Do not build yet. Falsify candidate #1 first. Explicit kill criterion: if practice-management/accounting products already map document-level exceptions to downstream blocked work with deadline/economic prioritization, reject horizontal version and rotate. Positive threshold before public web: evidence from at least 3 independent firms/workflows of repeated exception triage, plus one credible path to a pilot/sample. No outreach in Pablo's name without approval.
