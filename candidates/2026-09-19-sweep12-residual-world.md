# Sweep 12 — residual-value services + pet-waste B2B — 2026-09-19

## Pet-waste-removal-b2b-concentrated
Classification: POSSIBLE-ROTATED.

Bounded pass tested Spain/Galicia B2B node demand, contract value and density. Search found strong public concern around dog waste and active municipal procurement/ADN enforcement, but not evidence of a standalone private pet-waste-removal category for Galician residential nodes. Existing community-maintenance firms already bundle cleaning, gardens and common areas, making them the obvious substitute. The nearby recurring DTC proof remains valid, but the proposed B2B concentration wedge did not strengthen materially.

Decision: rotate. Revisit only on an explicit private-node contract, administrator demand, kennel/daycare economics, or another privileged dense channel.

## Residual-value-subsidized service search
The primitive is real but is not itself a moat.

### Corporate IT assets
Spanish ITAD/buyback operators already combine collection, valuation, certified data erasure, environmental traceability and resale/recovery value. TD SYNNEX explicitly offers this to partners as a way to recover customer value and create partner income; multiple national operators provide essentially the full loop. This is strong validation of `residual value funds adjacent pain removal`, but also shows that once residual value is liquid and standardized, specialists rapidly internalize the whole service stack.

Status: OBSERVED/OCCUPIED as generic ITAD. Do not build another buyback layer.

### Pallets
Used pallets also have explicit resale value and free collection in sufficiently valuable/dense lots. Again, the recovery operator normally owns collection and resale directly. Useful proof of the primitive, weak standalone opportunity.

### Toner/RAEE
Here the economics can invert: certified collection is sold from very low monthly prices while operators monetize treatment/recovery and compliance. This reinforces that the customer-facing pain can be subsidized by downstream economics, but the category is mature and nationally covered.

## New structural learning
Residual value is useful when it changes customer acquisition or service economics; it is not automatically an opportunity. Search should target cases where (1) the residual is fragmented or poorly priced, (2) the generator still pays separately for a nearby recurring pain, and (3) incumbents have not already vertically integrated both sides. Otherwise the residual simply strengthens the incumbent recycler/remarketer.

A potentially stronger pattern is `latent asset value + mandatory/risky lifecycle task + privileged distribution`. ITAD demonstrates all three but is occupied. Future WORLD sweeps should search for analogous assets outside conventional waste/recycling rather than repeatedly enumerating waste streams.
