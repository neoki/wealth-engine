# Public Folder Exit Planner — channel economics update (2026-09-15)

## Decision
KEEP / ADVANCE, but refine the MSP value proposition.

## New evidence
Fresh prospect research shows that free migration assessments are common in the MSP channel. Twin Technology advertises a free Microsoft 365 migration assessment. Synergi Tech also advertises a free assessment and says it audits the current environment and produces a fixed-price migration plan. AO Data Cloud describes inventory/audit of the source environment as the first phase of its migration process. Sale Systems reports 200+ migrations and markets migration consulting nationally in Spain. DTP Murcia, FuturaSP, Semat Data, NextIT Process Solutions and AO Data Cloud all publicly sell Microsoft 365/Exchange migration services in Spain. UK firms Core Technology Systems, Twin Technology, Synergi Tech, Avergent, Foxcomm and Valto provide further channel candidates, with Core explicitly listing managed Exchange Public Folder migration.

## Important interpretation
This does NOT weaken the product merely because assessment is sometimes free to the end customer. It changes who captures the value.

If an MSP gives assessment away to win a larger migration, then its assessment labour is customer-acquisition / pre-sales cost. A planner that compresses several engineer/consultant hours into minutes can improve the MSP's gross margin and allow it to quote more opportunities. Therefore the strongest initial message is not "sell a EUR 990 assessment" but:

> Turn a costly free migration assessment into a fast, repeatable sales asset.

The MSP can still charge the customer when appropriate, but Rockrai's ROI does not depend on that.

## Revised value equation
Partner value per report ≈ engineering hours avoided + faster quote turnaround + extra opportunities scoped + reduction in under-scoped project risk.

This suggests measuring willingness to pay against internal labour saved rather than against the retail assessment price alone.

## Offer tests
1. **Free first report** — zero-friction proof using a real/sanitised inventory.
2. **Per-report credits** — useful for low-volume MSPs; price should be materially below the labour saved.
3. **MSP subscription / white-label** — for recurring migration volume; branded reports and reusable assumptions/templates.
4. **Assisted review** — premium exception path when confidence is low or the project is complex.

Do not lock prices yet. The earlier USD 3,500 planning benchmark remains useful as evidence that planning can carry substantial value, but it is not the only anchor.

## Prospect evidence set — current strong/medium candidates
Spain: MSAdvance, FuturaSP, ITCM Solutions, DTP Murcia, Semat Data, NextIT Process Solutions, AO Data Cloud, Sale Systems.
UK/EU expansion: Core Technology Systems, Twin Technology, Synergi Tech, Avergent, Foxcomm, Valto.

This gives 14 named channel candidates with explicit public migration/assessment evidence, before broader prospecting. The target remains 20–50, with >=8 strong candidates.

## Product implication
The report should look like something an MSP can put in front of a prospect immediately. Prioritise:
- MSP logo/branding
- executive summary
- recommended destination by workload
- assumptions and confidence flags
- blockers requiring stakeholder confirmation
- migration waves
- scope/risk indicators that help create a quote
- explicit "requires human validation" boundaries

The product is therefore both technical analysis and sales-enablement infrastructure.

## Next gate
Expand to >=20 qualified MSPs and test whether the generated report is credible enough to replace a meaningful part of pre-sales discovery/scoping. A public Rockrai subdomain is not yet necessary; build distribution evidence first.
